# DvP

**键盘即鼠标。** 右手放在 IJKL 上移动光标，左手控制点击和滚动——再也不用把手从键盘上挪开去摸鼠标。

> v0.2 重写了整个速度引擎，借鉴 ThinkPad TrackPoint 的三段式力-速曲线。现在轻触稳如像素级微调，长按快如跨屏飞掠。

## 它是怎么工作的

```
你的键盘  ──▶  DvP 全局监听  ──▶  翻译成鼠标事件  ──▶  注入系统
```

DvP 在 macOS 的 HID 事件层插入一个「翻译层」。当你按下 IJKL 时，它把键盘事件拦截下来，换算成对应的光标移动、点击或滚动事件，再注入回系统。整个过程在 120 Hz 下运行。

**隐私说明：** DvP 完全在本地运行，不上传任何数据。所需的「辅助功能权限」仅用于监听全局按键和注入鼠标事件，不读取屏幕内容。

## 菜单栏图标

DvP 常驻在 macOS 菜单栏右上角，显示淡蓝色 **DvP** 文字。图标会随当前状态变化：

| 图标 | 含义 |
|------|------|
| DvP 实心蓝字 | 光标模式 — IJKL 正在控制光标 |
| DvP 描边蓝字 | 待机中 — 按 `Esc + I` 激活 |
| DvP 半透明蓝字 | 缺少权限 / 输入模式 |

点击图标弹出菜单，可以看到权限状态、当前模式、以及「重新检查权限」按钮。

## 三种模式

DvP 有三个模式，用快捷键在它们之间切换：

```
                    Esc + I
      待机 (Normal) ◄──────► 光标模式 (Cursor)
                                │
                                │  U
                                ▼
                          输入模式 (Input)
                                │
                                │  Esc + U
                                ▼
                           光标模式 (Cursor)
```

### 待机模式

默认状态。键盘完全正常，DvP 不干涉任何输入。图标显示描边蓝字。

### 光标模式

DvP 接管键盘——你的按键不再输入文字，而���被翻译成鼠标操作。图标显示实心蓝字。Cmd/Opt/Ctrl 修饰的系统快捷键（截屏、复制粘贴等）自动放行。

### 输入模式

临时恢复键盘打字。比如浏览网页时需要输入账号密码：按 `U` 进入输入模式，打完字后按 `Esc + U` 回到光标模式。图标显示半透明蓝字。

所有快捷键仅在**光标模式**下生效。建议把右手食指放在 `J`（有凸点）上，其余手指自然覆盖 `I` `K` `L`。

## 速度引擎（v0.2 重点）

v0.2 完全重写了速度模型。旧版用的是简单的三次方加速——前慢后猛，缺乏中间过渡。新版借鉴 **ThinkPad TrackPoint 小红点** 的三段式设计，实现了三个相互配合的机制：

### 1. Sigmoid 力-速曲线

```
v(t) = 1 + (cap − 1) × S(k × (t − t₀))
```

按键持有时长 `t` 通过 S 形函数映射到加速倍率：

- **0 – 0.7 秒**：精度区。ramp 接近 1x，光标缓慢移动，适合像素级微调和精准点击。
- **0.7 秒附近**：拐点。速度开始自然爬升，过渡平滑不突兀。
- **1.5 秒以上**：高速区。ramp 接近 30x 上限，跨屏飞掠。

旧版三次方曲线在 0.5 秒前几乎不动、0.5 秒后突然起飞，新版 Sigmoid 的过渡是连续的——木有「跳速」的感觉。

### 2. 负惯性（Negative Inertia）

这是 TrackPoint 的标志性技术。它检测的不是按键力度本身，而是力度的**变化率**——即导数：

```
boost = speed × min(ramp 变化率, 50) × inertiaFactor
```

你按得越快（力度变化越大），助推越大。轻轻按下≈小助推，猛敲一下≈大助推。这让光标感觉「轻」——轻轻一点就动，不需要用力按住。

> TrackPoint 默认负惯性系数为 6；DvP 调教后定为 3，更适合键盘按键的物理特性。

### 3. 反向急停（Counter-strafe）

来自 FPS 游戏的设计：当光标在某个方向移动时，按下**相反方向**的键，该方向速度立刻清零，然后立即开始反向移动。

```
往右冲 → 按 J（左）→ 立刻停，马上往左走
往下冲 → 按 I（上）→ 立刻停，马上往上走
```

没有过渡延迟，跟 FPS 游戏里反方向键急停的手感一致。

### 可调参数

所有参数集中在 [`Sources/CursorEngine.swift`](Sources/CursorEngine.swift)，重新编译即生效：

| 参数 | 当前值 | 作用 |
|------|--------|------|
| `baseSpeed` | 35 | 基础速度（像素/秒），精度区的起速 |
| `shiftMultiplier` | 2.0 | 按住 `;` 时的速度倍率 |
| `maxSpeed` | 3500 | 绝对速度上限（像素/秒） |
| `smoothing` | 0.25 | 速度平滑 lerp 因子，越小越跟手 |
| `sigmoidMidpoint` | 0.70 | 拐点（秒），小数点前都在精度区 |
| `sigmoidSteepness` | 7.0 | 过渡陡度，越高越突兀 |
| `accelerationCap` | 30.0 | 加速倍率上限 |
| `negativeInertia` | 3.0 | 负惯性因子，0 = 关 |

## 安装

### 系统要求

- macOS 14.0 Sonoma 或更高
- Apple Silicon Mac（Intel 未测试但理论上兼容）

### 方法一：下载（推荐）

从 [Releases](../../releases) 页面下载最新版 `DvP.app`，拖到 `/Applications/` 双击运行。首次启动会弹窗要求辅助功能权限。

> ⚠️ macOS 可能会提示「无法验证开发者」。到**系统设置 → 隐私与安全性**中点击「仍要打开」。

### 方法二：从源码编译

```bash
git clone git@github.com:PeterkingPanpan/DvP.git
cd DvP

# 一键编译 + 打包（生成 DvP.app）
bash bundle.sh

# 拖到 Applications
cp -R DvP.app /Applications/

# 首次启动
open /Applications/DvP.app
```

### 授予权限

首次运行会自动弹窗。如果没有弹窗或授权后仍显示「未授权」：

1. 打开 **系统设置 → 隐私与安全性 → 辅助功能**
2. 找到 DvP，**先关掉再打开**（触发 TCC 重新绑定）
3. 等待 3 秒——DvP 会自动检测权限变化，图标变亮即表示就绪

> **为什么需要「关掉再打开」？** macOS 的 TCC（隐私权限数据库）以代码签名为身份标识。如果你从旧版本升级、或重新编译了源码，签名身份可能不匹配，需要开关一次让系统重新绑定。

## 快速上手

第一次用建议这样练习：

1. 点菜单栏 DvP 图标，确认权限 ✓
2. 把右手食指放在 `J` 的凸点上，其余手指覆盖 `I` `K` `L`
3. 按 `Esc + I`，看到图标变成实心蓝字
4. 试试 `IJKL` 移动光标——轻触慢、长按快，感受 Sigmoid 曲线
5. 光标移到文件夹上，短按 `Space` 点击
6. 打开网页，`Shift + W/S` 试试滚动
7. 按 `Esc + I` 退回待机模式

**练习建议：** 每天花 10 分钟用 DvP 替代鼠标做日常操作，三天就能上手。

## 常见问题

### 双击打开 DvP.app 没有反应？

DvP 是菜单栏应用，没有 Dock 图标。打开后看屏幕右上角菜单栏，淡蓝色「DvP」字样就是了。重复双击会提示「已在运行」，这是单实例保护在起作用。

### 光标撞到屏幕边缘卡住了？

v0.2 已修复——碰到屏幕边缘自动清零该方向速度，按反方向键即可返回。

### 想调整移动速度？

编辑 `Sources/CursorEngine.swift` 中的参数后重新运行 `bash bundle.sh`。参数含义见[速度引擎](#速度引擎v02-重点)章节。

### 菜单栏图标太淡？

默认使用淡蓝色文字。你可以在 `AppDelegate.swift` 中修改 `iconColor` 的颜色值后重新编译。

### 支持 Windows / Linux 吗？

目前仅支持 macOS。
