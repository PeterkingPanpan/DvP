# DvP

**键盘即鼠标。** 右手放在 IJKL 上移动光标，左手控制点击和滚动——再也不用把手从键盘上挪开去摸鼠标。

DvP 在 macOS 的 HID 事件层插入一个「翻译层」：监听全局键盘事件，把 IJKL 翻译成光标移动、Space 翻译成点击、WASD 翻译成方向键/滚轮，再注入回系统。全程 120 Hz，完全本地运行，不上传任何数据。所需的「辅助功能权限」仅用于监听全局按键和注入鼠标事件，不读取屏幕内容。

## 安装

### 系统要求

- macOS 14.0 或更高
- Apple Silicon（Intel 理论上兼容）

### 从源码编译

```bash
git clone git@github.com:PeterkingPanpan/DvP.git
cd DvP
bash bundle.sh          # 编译 + 打包，生成 DvP.app
open DvP.app
```

首次启动会要求**辅助功能权限**：

1. 系统设置 → 隐私与安全性 → 辅助功能
2. 找到 DvP，打开开关（若图标仍半透明，先关掉再打开一次）
3. 3 秒内菜单栏图标从半透明变成实心/描边蓝字，即授权成功

## 快速上手

1. 点菜单栏 **DvP** 图标，确认权限 ✓
2. 右手食指放在 `J` 的凸点上，其余手指覆盖 `I` `K` `L`
3. 按 `Esc + I`，图标变实心蓝字（进入光标模式）
4. 试 `IJKL` 移动光标——轻触慢、长按快
5. 光标移到图标上，短按 `Space` 点击；`N` 右键，`M` 中键
6. 打开网页，`Shift + W/S` 上下滚动
7. 按 `Esc + I` 退回待机

## 三种模式

| 模式 | 说明 | 图标 |
|------|------|------|
| 待机 | 默认状态，键盘完全正常 | 描边蓝字 |
| 光标控制 | DvP 接管键盘 | 实心蓝字 |
| 临时输入 | 暂时恢复打字 | 半透明蓝字 |

- `Esc + I` — 待机 ↔ 光标（开关机）
- `U` — 光标 → 输入
- `Esc + U` — 输入 → 光标

## 默认键位

所有键位仅在**光标模式**下生效，且都能在配置窗口里修改。

### 光标移动 — 右手

| 按键 | 动作 |
|------|------|
| `I` `J` `K` `L` | ↑ ← ↓ → |
| `;` | 按住加速（速度翻倍） |
| `H` | 瞬移到屏幕中央 |

### 点击 — 左手

| 按键 | 动作 |
|------|------|
| `Space` | 左键（短按单击、长按拖拽） |
| `/` | 左键双击 |
| `N` | 右键 |
| `M` | 中键 |
| `O` | 回车 |

### 方向键与滚动

| 按键 | 动作 |
|------|------|
| `W` `A` `S` `D` | 方向键 |
| `Shift + W/S` | 垂直滚动 |
| `Shift + A/D` | 水平滚动 |

## 可视化配置

点菜单栏 **DvP → 配置…** 打开配置窗口：

- **可视化键盘** —— 完整 QWERTY 布局。已绑定的键有淡蓝色底；点某个键选中它；实际按键时对应键帽实时点亮。
- **改键** —— 选中一个键，右侧可选内建动作（移动 / 点击 / 滚轮 / 回车 / 瞬移…），或点「录制快捷键」录一个组合键（如 `⌘C`）放上去。
- **调速** —— 底部「速度」滑块调基础速度；展开「高级」可调加速手感（最快速度、跟手程度、何时开始加速等），并实时看到加速曲线。
- **即时生效 + 自动保存** —— 改动立刻作用于引擎，并保存到 `~/Library/Application Support/DvP/config.json`。「恢复默认」一键还原。

## 速度引擎

借鉴 ThinkPad TrackPoint 小红点的手感：

1. **Sigmoid 力-速曲线** —— 轻触几乎不加速（像素级微调），按住约 0.7 秒后速度爬升，长按到 30 倍飞掠。
2. **负惯性** —— 按得越「猛」，助推越大，光标有轻快感。
3. **反向急停** —— 反向键一按，该方向速度立刻清零。

所有参数都能在配置窗口里调，无需改代码。

## 常见问题

### 双击打开没反应？

DvP 是菜单栏应用，没有 Dock 图标，看屏幕右上角菜单栏的「DvP」字样。

### 授权了仍显示未授权？

到 系统设置 → 隐私与安全性 → 辅助功能 里把 DvP **先关掉再打开**一次。只要 `bundle.sh` 一直用同一个签名证书，之后重编译不会失效。

### 光标撞到屏幕边缘卡住？

已修复——碰到边缘自动清零该方向速度，按反方向键即可返回。

### 支持 Windows / Linux？

目前仅 macOS。
